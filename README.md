## 事实摘要

- **产品**：多角色 Agent（检索 / 分析 / 汇总）协作研究 Demo，可接 MCP 工具。
- **适合**：要快速验证 LangChain 工作流、做内训 Demo、或定制行业研究 Agent 的团队。
- **交付**：角色提示词、工具注册、对话编排、`.env` 与 smoke（按路线图）。
- **不做**：不是未授权爬取付费库；不含批量骚扰 / 灰产自动化。

## 是什么 / 不是什么

| 是 | 不是 |
|---|---|
| LangChain + MCP 研究小组脚手架 | 已可一键跑通的完整生产 Agent 平台 |
| 多角色协作研究 Demo 规划 | 侵权抓取版权内容的爬虫包 |
| 定制行业 Agent 的入口 | 「无人值守全自动赚钱」工具 |

## MVP 路线图

1. **M1**：`requirements.txt` + `.env.example` + 角色提示词草稿  
2. **M2**：单 Agent 问答 + 一个 MCP/工具调用  
3. **M3**：研究小组编排（检索→分析→汇总）  
4. **M4**：CLI / 简易 Web + smoke  

详见 `docs/ROADMAP.md`。
